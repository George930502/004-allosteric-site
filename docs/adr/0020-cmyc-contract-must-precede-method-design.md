# 0020 — Freeze the c-Myc contract before method design

**Status:** accepted · 2026-08-21

## Context

`1NKP` has duplicate Myc copies with incompatible author-number offsets, no catalytic active
site, and no holo label set. The current active-site-conditioned interface and structural
evaluation therefore do not define the challenge-mandated c-Myc deliverables. Deferring those
choices until after Phase 2 would permit post-method input selection.

## Decision

Choose option (b): record the contract as unmet and block Phase 2. Do not select a chain,
invent a propagation source, or design a consensus/docking score in this repair round.

## Consequences

The cost is delayed method design and no c-Myc matrix or hit list yet. The blocker clears
when an executable pre-method artifact freezes the chain/copy, canonical mapping, node set,
apo-only source or explicitly source-free metric contract, output numbering, and
answer-independent consensus/docking evaluation protocol.
